# Multi Factor Authentication

## Enrolling a device

Enrol at https://id.jenosize.example/mfa using the authenticator application.
Hardware security keys are supported and are required for administrators and
for anyone with production access.

## Replacing a lost factor

A lost phone is handled by the service desk after an identity check over video
call. Backup codes issued at enrolment can also be used once each. Store them
somewhere other than the device that generates the codes.

## Why push approval was removed

Simple push approval was replaced with number matching because attackers were
flooding users with prompts until one was accepted by mistake. Number matching
requires the code shown on screen to be typed into the application.

## Travel

No exception is needed for travel. If you expect to be without mobile
coverage, request a hardware key before departure.
