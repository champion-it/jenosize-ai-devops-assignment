# Software Installation

## Self service catalogue

Approved applications install without a ticket from the company portal. The
catalogue covers browsers, editors, communication tools and common developer
runtimes.

## Requesting unlisted software

Software outside the catalogue needs a request that names the business reason
and the licence model. Security reviews the vendor before approval. Allow five
business days for a first time vendor.

## Administrator rights

Standard accounts do not have local administrator rights. Engineers can
request time limited elevation that lasts eight hours and is logged. Permanent
administrator rights are not granted on managed laptops.

## Unapproved software

Installing unapproved software on a managed device breaches the acceptable use
policy. The endpoint agent reports unknown binaries and the service desk will
contact you before any enforcement action is taken.
